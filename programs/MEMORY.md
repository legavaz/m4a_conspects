# Память проекта: Zoom-записи → конспекты

> Файл состояния. Обновляется вручную после значимых изменений.

## Цель

Система записи Zoom-встреч (аудио) и создания структурированных конспектов:
локальная транскрибация (whisper.cpp) → суммаризация LLM → сохранение рядом с аудио и в Obsidian.

## Ключевые технические факты

- **Кириллица в .ps1** — только UTF-8 **с BOM** (иначе PowerShell 5.1 ломает строки).
- **Таймкоды**: whisper-cli пишет `.srt` (флаг `-osrt`) — основной источник таймкодов для конспекта. Раньше `-otxt` давал текст без меток.
- **VAD-модель**: автозагрузка из `https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin`.
  В `ggerganov/whisper.cpp` VAD нет (404); `ggml-org/whisper.cpp` — gated (401).
- **Баг whisper-cli** на длинных файлах: падение `-1073740791` (0xC0000409) или
  `failed to allocate buffer of size 53760000` / `-1073741819` (0xC0000005) даже при 15 ГБ свободной ОЗУ.
  **Теперь автоматизировано в `transcribe.ps1`**: повторы (`-Retries`, по умолчанию 2) → фолбэк: нарезка WAV на куски `-ChunkSeconds` (600 с) + `ggml-small`, затем склейка `.txt` и `.srt` (со сдвигом таймкодов). Отключается флагом `-NoFallback`.
- **Кодировка объединения**: chunk-файлы whisper — UTF-8. Объединять через
  `[System.IO.File]::ReadAllText(..., UTF8)`, а не `Get-Content` без `-Encoding UTF8` (иначе mojibake).
- Артефакт whisper: иногда ~2,5 мин зацикленной фразы в конце (напр. «Реализация по контрагентам») — в конспект не включать.
- Русского SAPI-голоса нет (только Microsoft Zira Desktop en-US) — тесты делались английской речью.

## Состояние обработки (SQLite)

- БД: `D:\video_cast\zoom\state.db`; CLI: `programs\zoom_state.py` (Python, sqlite3 — новых зависимостей нет).
- Статусы: `new` (нет транскрипта) → `transcribed` (есть `.txt`/`.srt`) → `done` (есть `_конспект.md`); `deleted` — файл пропал.
- `sync` сверяет БД с файлами по `size`/`mtime` (при перезаписи — сброс в `new`), докручивает статусы из файлов. **Не транскрибирует.**
- `pending` → `no_transcript` (пропускаем) и `ready_for_konspekt` (делаем конспект).
- **Правило: транскрибацию не запускать автоматически.** Файлы без транскрипта пропускаем; при необходимости — сначала спросить пользователя.
- После конспекта: `mark "<аудио>" done --konspekt .. --obsidian ..` (или `sync` подхватит `_конспект.md`).
- Текущее состояние (2026-09-16): `done=6` (15.09), `transcribed=1` (14.09, тест «Проверка связи»), `new=2` (webm 14.09, `Zoom_20260916_121356.m4a`).

## Структура сохранения конспектов

### Рядом с аудио
`<папка встречи>\<имя>_конспект.md`

### В Obsidian (Год/Месяц/Дата)
`Обсидиан/Встречи Zoom/ГГГГ/ММ/ГГГГ-ММ-ДД/ЧЧ-ММ — <тема>.md`
- дата — в пути папки; в имени заметки **час-минуты + тема** (записи дня идут по времени).
- Vault: `E:\Обсидиан\Обсидиан`, заметки с префиксом `Обсидиан/`.

## Требования к конспекту (из prompt-konspekt.md)

Шапка (дата, время, длительность, файл) · участники (неуверенные — `(?)`) ·
кратко (3–5 предложений) · темы с таймкодами `[чч:мм]` (из `.srt`) ·
решения/договорённости (кто/что/срок) · ❗важное с `==подсветкой==` · открытые вопросы ·
не выдумывать, `[неразборчиво]`, имена/термины (1С, ИТ) корректно, деловой тон.
