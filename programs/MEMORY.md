# Память проекта: Zoom-записи → конспекты

> Файл состояния. Обновляется вручную после значимых изменений.

## Цель

Система записи Zoom-встреч (аудио) и создания структурированных конспектов:
локальная транскрибация (GigaAM-v3 по умолчанию; резерв — Nemotron/whisper) → суммаризация LLM → сохранение рядом с аудио и в Obsidian.

## Ключевые технические факты

- **Кириллица в .ps1** — только UTF-8 **с BOM** (иначе PowerShell 5.1 ломает строки).
- **Таймкоды**: whisper-cli пишет `.srt` (флаг `-osrt`) — основной источник таймкодов для конспекта. Раньше `-otxt` давал текст без меток.
- **VAD-модель**: автозагрузка из `https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin`.
  В `ggerganov/whisper.cpp` VAD нет (404); `ggml-org/whisper.cpp` — gated (401).
- **Баг whisper-cli** на длинных файлах: падение `-1073740791` (0xC0000409) или
  `failed to allocate buffer of size 53760000` / `-1073741819` (0xC0000005) даже при 15 ГБ свободной ОЗУ.
  **Теперь автоматизировано в `transcribe.ps1`**: повторы (`-Retries`, по умолчанию 2) → фолбэк: нарезка WAV на куски `-ChunkSeconds` (600 с) + `ggml-small`, затем склейка `.txt` и `.srt` (со сдвигом таймкодов). Отключается флагом `-NoFallback`.
- **Кодировка объединения**: chunk-файлы whisper — UTF-8. Объединять через
  `[System.IO.File]::ReadAllText(..., UTF8)`, а не `Get-Content` без `-Encoding UTF8` (иначе mojibake).
- Артефакт whisper: иногда ~2,5 мин зацикленной фразы в конце (напр. «Реализация по контрагентам») — в конспект не включать.
- Русского SAPI-голоса нет (только Microsoft Zira Desktop en-US) — тесты делались английской речью.
- **Копирование в Obsidian**: после записи проверять, что заметка реально создана с расширением `.md` и не 0 байт —
  18.09 обнаружен артефакт «10-01 — Оперативка» (пустой файл без расширения) рядом с настоящими заметками.
  **Причина артефактов с пустым именем — двоеточие в теме** (NTFS трактует `:` как ADS-разделитель, создаётся
  пустой файл без .md до двоеточия); 20.10 это повторилось с «14-57 — Недельная планёрка: …» — в именах
  заметок двоеточие заменять на «—».
  **Уровень vault (важно, 13.10):** корень vault Obsidian — `E:\Обсидиан\Обсидиан` (там каталог `.obsidian`;
  подтверждено `%APPDATA%\obsidian\obsidian.json` и открытым файлом `Обсидиан/Встречи Zoom/2026/10/...` в `workspace.json`).

## Состояние обработки (SQLite)

- БД: `D:\video_cast\zoom\state.db`; CLI: `programs\zoom_state.py` (Python, sqlite3 — новых зависимостей нет).
- Статусы: `new` (нет транскрипта) → `transcribed` (есть `.txt`/`.srt`) → `done` (есть конспект); `no_speech` — оба файла существуют, но пустые (речи нет, повторно не обрабатывается); `deleted` — файл пропал.
- **Сессии** — одна логическая встреча = 1+ записей (когда встречи идут одна за одной как продолжение).
  `session auto --gap 30` предлагает группы по зазору; `session merge/split` — ручной контроль;
  `session done <id>` помечает все файлы сессии одним конспектом. На сессию — один конспект.
- `sync` сверяет БД с файлами по `size`/`mtime`, докручивает статусы; **учитывает сессии** (файл сессии с готовым
  конспектом не откатывается в `transcribed`). **Не транскрибирует.**
- `pending` → `no_transcript` (пропускаем) и `ready_for_konspekt` (готово к конспекту; сгруппировано по сессиям).
- **Правило: транскрибацию вручную не запускать без согласия.** Плановая транскрибация — только почасовой джоб (`hourly.ps1`), он берёт записи из статуса `new`; `sync`/`pending` ничего не транскрибируют.
- После конспекта: `session done <id>` для сессии или `mark "<аудио>" done --konspekt .. --obsidian ..` для одиночного файла.

## Параметры транскрибации

- **Движок по умолчанию — GigaAM-v3 e2e-RNN-T** (`-Engine gigaam`, `programs\transcribe_gigaam.py`), затем Nemotron, резерв — whisper.
  - Модель: `istupakov/gigaam-v3-onnx` (fp32/int8), локально `models\gigaam-v3-e2e-rnnt` (fp32 ~890 МБ). Русский, на выходе — регистр и пунктуация.
  - Окружение: отдельный venv `.venv-gigaam` (Python 3.12, `uv venv --python 3.12 .venv-gigaam` + `uv pip install --python .venv-gigaam\Scripts\python.exe "onnx-asr[hub]" onnxruntime-directml`). В системный Python не ставить.
  - Длинные записи — Silero VAD (`onnx_asr.load_vad("silero")`), без лимита 25 с; VAD-сегменты → `.srt`, склейка → `.txt`.
  - **GPU (RTX 5050, Blackwell sm_120)**: работающий путь — **DirectML** (`DmlExecutionProvider`, пакет `onnxruntime-directml`), ~**34x realtime**; CPU ~16x.
    **CUDA недоступна**: `onnxruntime-gpu` 1.31 требует CUDA 13 + cuDNN 9, а драйвер 576.88 (макс. CUDA 12.9) — драйвер ниже минимума CUDA 13 (нужен ≥580). Провайдер тихо откатывается на CPU, поэтому провайдер проверяем реальной ORT-сессией (`sess.get_providers()`), а не через `get_available_providers()`.
  - Провайдеры: `-GigaamProvider auto` (по умолч.; cuda→dml→cpu) | `cuda` | `dml` | `cpu`. Модель — `-GigaamModel`, python — `-GigaamPython`.
- **Nemotron 3.5 ASR** (`-Engine nemotron`), резерв — whisper. Команда: `nemo-speech transcribe <wav> --model nemotron-3.5 --language ru --device cpu --format srt --output <файл>.srt`
  (SRT-куски по границам предложений/пауз; `.txt` собирается из `.srt` функцией `Get-TxtFromSrt`).
- whisper: `ggml-large-v3-turbo.bin` по умолч.; быстрый черновой — `-Model ggml-small.bin`.
- whisper-cli v1.8.2, `-l ru`, `--vad -vm <модель>`, `-t 14` (потоков), `-otxt -osrt`.
- Пакетно: `transcribe-all.ps1 [-Path <папка>] [-Engine gigaam|nemotron|whisper] [-Model ...] [-DeleteTxt] [-Force] [-NoPause]`.
  По умолчанию ждёт `Enter` в конце (чтобы при запуске двойным кликом по ярлыку `transcribe-all.ps1.lnk`
  не закрывалось окно и были видны итог/ошибки); `-NoPause` — для автоматизации; при перенаправленном
  вводе (`[Console]::IsInputRedirected`) пауза не срабатывает. Ошибки ловятся и печатаются (не «молчаливое» закрытие).
  Ярлык `transcribe-all.ps1.lnk` (в корне проекта) запускает через `powershell -NoProfile -ExecutionPolicy Bypass -File`.
- **Внимание (stderr движков)**: `nemo-speech` и `whisper-cli` пишут прогресс в stderr. При
  `$ErrorActionPreference="Stop"` перенаправленный `2>&1` рендерится красным `NativeCommandError`
  (выглядит как падение, хотя транскрибация успешна). Решение в `transcribe.ps1`: вокруг вызова
  временно ставить `$ErrorActionPreference='Continue'` и гнать `2>&1 | ForEach-Object { Write-Host ([string]$_) }`.
  Так делают и `Invoke-NemotronPipeline`, и `Invoke-Whisper`.
