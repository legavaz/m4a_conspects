## Ключевые технические факты

- **Кириллица в .ps1** — только UTF-8 **с BOM** (иначе PowerShell 5.1 ломает строки).
- **Таймкоды**: whisper-cli пишет `.srt` (флаг `-osrt`) — основной источник таймкодов для конспекта. Раньше `-otxt` давал текст без меток.
- **VAD-модель**: автозагрузка из `https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin`.
  В `ggerganov/whisper.cpp` VAD нет (404); `ggml-org/whisper.cpp` — gated (401).
- **Баг whisper-cli** на длинных файлах: падение `-1073740791` (0xC0000409) или
  `failed to allocate buffer of size 53760000` / `-1073741819` (0xC0000005) даже при 15 ГБ свободной ОЗУ.
  **Теперь автоматизировано в `transcribe.ps1`**: повторы (`-Retries`, по умолчанию 2) → фолбэк: нарезка WAV на куски `-ChunkSeconds` (600 с) + `ggml-small`, затем склейка `.txt` и `.srt` (со сдвигом таймкодов). Отключается флагом `-NoFallback`.
- **Кодировка объединения**: chunk-файлы whisper — UTF-8. Объединять через
  `[System.IO.File]::ReadAllText(..., UTF8)`, а не `Get-Content` без `-Encoding UTF8` (иначе mojibake).
- Артефакт whisper: иногда ~2,5 мин зацикленной фразы в конце (напр. «Реализация по контрагентам») — в конспект не включать.
- Русского SAPI-голоса нет (только Microsoft Zira Desktop en-US) — тесты делались английской речью.
- **Копирование в Obsidian**: после записи проверять, что заметка реально создана с расширением `.md` и не 0 байт —
  18.09 обнаружен артефакт «10-01 — Оперативка» (пустой файл без расширения) рядом с настоящими заметками.

## Состояние обработки (SQLite)

- БД: `D:\video_cast\zoom\state.db`; CLI: `programs\zoom_state.py` (Python, sqlite3 — новых зависимостей нет).
- Статусы: `new` (нет транскрипта) → `transcribed` (есть `.txt`/`.srt`) → `done` (есть конспект); `deleted` — файл пропал.
- **Сессии** — одна логическая встреча = 1+ записей (когда встречи идут одна за одной как продолжение).
  `session auto --gap 30` предлагает группы по зазору; `session merge/split` — ручной контроль;
  `session done <id>` помечает все файлы сессии одним конспектом. На сессию — один конспект.
- `sync` сверяет БД с файлами по `size`/`mtime`, докручивает статусы; **учитывает сессии** (файл сессии с готовым
  конспектом не откатывается в `transcribed`). **Не транскрибирует.**
- `pending` → `no_transcript` (пропускаем) и `ready_for_konspekt` (готово к конспекту; сгруппировано по сессиям).
- **Правило: транскрибацию не запускать автоматически.** Файлы без транскрипта пропускаем; при необходимости — сначала спросить пользователя.
- После конспекта: `session done <id>` для сессии или `mark "<аудио>" done --konspekt .. --obsidian ..` для одиночного файла.
- Текущее состояние (2026-09-18, вечер): обработаны 15.09–18.09, `pending` пуст (остался только webm 14.09 без транскрипта).
  Сессии: 15.09 (OpenCode 15:00+15:43), 17.09 (моб. приложение 10:58+11:39), 18.09 (оперативка 10:01+10:39+11:19+12:00),
  18.09 (ЗУП/структура 15:46+16:24, сессия #5, объединена вручную — зазор ~38 мин > гэпа 30 с).
  Урок: `sync` в момент запуска мог не видеть свежие `.srt`/`.txt` — после транскрибации всегда перезапускать `sync` перед `pending`.

## Структура сохранения конспектов

### Рядом с аудио
`<папка встречи>\<имя>_конспект.md`

### В Obsidian (Год/Месяц/Дата)
`Обсидиан/Встречи Zoom/ГГГГ/ММ/ГГГГ-ММ-ДД/ЧЧ-ММ — <тема>.md`
- дата — в пути папки; в имени заметки **час-минуты + тема** (записи дня идут по времени).
- Vault: `E:\Обсидиан\Обсидиан\Обсидиан` (внутри корня vault — папка `Обсидиан`, т.е. полный путь заметки:
  `E:\Обсидиан\Обсидиан\Обсидиан\Встречи Zoom\ГГГГ\ММ\ГГГГ-ММ-ДД\...`). Проверять фактический vault-путь перед копированием.

## Требования к конспекту (из prompt-konspekt.md)

Компактный формат: YAML-frontmatter (дата/начало/длительность/файлы/участники/теги) ·
`**Суть**` одной строкой · Решения таблицей (кто/что/срок) · Поручения чек-листом `- [ ]` ·
Хронология `[мм:сс] тема — фраза` (подробный блок — по запросу) · ❗Риски/цифры с `==подсветкой==` ·
Открыто чек-листом `- [ ]`. Для сессии: `начало` — по первому файлу, `длительность` — суммарная, `файлы` — все.
Не выдумывать, `[неразборчиво]`, имена/термины (1С, ИТ) корректно, деловой тон.
