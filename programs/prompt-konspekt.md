# Стандартный промпт для конспекта встречи (opencode)

Триггеры — короткая фраза в opencode:

```
Конспект: <папка>            # обработать новые записи в папке
Конспект: <путь к .m4a>      # один файл
```

Состояние обработки ведётся в БД (`programs\zoom_state.py`, SQLite `state.db`) —
чтобы не перепроверять каждый файл и не гонять лишний раз.

---

## Порядок работы

1. **Синхронизируй состояние** (ничего не транскрибирует, только сверяет БД с файлами):
   ```
   python programs\zoom_state.py sync
   python programs\zoom_state.py pending --json
   ```
2. **Разбери список `pending`:**
   - `ready_for_konspekt` — есть транскрипт (`.txt`/`.srt`), конспекта ещё нет → **делаем конспект**;
   - `no_transcript` — транскрипта нет → **пропускаем** и просто перечисляем в отчёте.
   - **Транскрибацию НЕ запускать** без крайней необходимости. Если файл реально нужен,
     сначала **спросить пользователя**; только после согласия — `transcribe.ps1 <файл>`.
3. **Для каждого файла из `ready_for_konspekt`** составь конспект в Markdown (ниже).
4. **Сохрани** рядом с аудио и в Obsidian (ниже) и **отметь в БД**:
   ```
   python programs\zoom_state.py mark "<аудио>" done ^
       --konspekt "<папка>\<имя>_конспект.md" ^
       --obsidian "Обсидиан/Встречи Zoom/ГГГГ/ММ/ГГГГ-ММ-ДД/ЧЧ-ММ — <тема>.md"
   ```
   (Если забыть — `sync` подхватит `_конспект.md` и сам переведёт в `done`.)

## Структура конспекта

- **Шапка**: дата, время (из имени `Zoom_ГГММДД_ЧЧММСС`), длительность (из `.srt`/ffprobe), исходный файл.
- **Участники**: кого видно из представлений/обращений; неуверенные — с пометкой `(?)`.
- **Кратко**: 3–5 предложений сути встречи.
- **Темы**: по блокам, с таймкодами `[чч:мм]` (из `.srt`) и содержанием.
- **Решения и договорённости**: кто / что / срок.
- **❗Важное**: цифры, риски, дедлайны, цитаты — `==подсветкой==`.
- **Открытые вопросы**: что осталось нерешённым.

## Правила

- ничего не выдумывай; опирайся только на транскрипт;
- неразборчивые места помечай `[неразборчиво]`;
- имена и термины (1С, ИТ) пиши корректно (см. `MEMORY.md`);
- тон — деловой, без воды.

## Сохранение (два места)

- рядом с аудио: `<папка дня>\<имя>_конспект.md`;
- в Obsidian: `Обсидиан/Встречи Zoom/ГГГГ/ММ/ГГГГ-ММ-ДД/ЧЧ-ММ — <тема>.md`
  (дата — в пути папки; в имени заметки только **час-минуты и тема**, чтобы записи дня шли по порядку).

---

## Примечания

- Транскрипция полностью локальная (токены LLM не расходуются); токены тратятся только на чтение транскрипта моделью и генерацию конспекта (~20–30 тыс. на часовую встречу).
- Таймкоды берём из `.srt` (флаг `-osrt` в `transcribe.ps1`), текст — из `.srt`/`.txt`.
- Быстрый/черновой вариант транскрибации (если попросят): `-Model ggml-small.bin`.
- Экономия места: `transcribe.ps1 -DeleteTxt` удалит `.txt`, оставив `.srt`.
