# Промпт-команда автономного конспекта (вызывается `konspekt.ps1`)

Цель обработки — в строке `Target:` сообщения запуска; если её нет — весь проект
`D:\video_cast\zoom`.

Ты выполняешь стандартный регламент конспекта встречи. Сначала прочитай файл
`programs\prompt-konspekt.md` целиком и строго следуй ему.

Действия:
1. Синхронизируй состояние: `python programs\zoom_state.py sync`, затем
   `python programs\zoom_state.py pending --json`.
2. Разбери `pending`: `ready_for_konspekt` — готовые сессии/файлы для конспекта;
   `no_transcript` — пропусти, транскрибацию самостоятельно не запускай
   (форматы записи любые — `.m4a`, `.webm`, `.mp4`, `.mp3`, `.wav`, `.ogg`, `.m4b` — все
   можно транскрибировать, но делается это только с согласия пользователя).
3. Для каждой готовой сессии — ОДИН компактный конспект по шаблону из регламента
   (frontmatter обязателен; на сессию: начало по первому файлу, длительность суммарная,
   файлы — все файлы сессии). Стиль: обязательный обзорный абзац (executive summary),
   решения — законченными фразами, хронология — короткая (3–7 якорей) или отсутствует.
   Разделы: «Ключевые решения», «Важные обновления статуса», «Следующие шаги», «Открытые вопросы».
   **Длинный транскрипт (> ~1500 строк .srt) читай диапазонами по 400–800 строк**, иначе контекст
   переполнится и конспект молча не запишется. Всегда дочитывай все части сессии.
4. Сохрани конспект **только рядом с аудио**: `<первый файл сессии>_конспект.md`.
   **В Obsidian вручную ничего не пиши** — заметку создаст команда ниже (это гарантирует, что
   локальный файл и заметка идентичны; ручное написание даёт дубли и расхождения).
   Имя заметки: `ЧЧ-ММ — <тема>.md`, путь от корня vault `E:\Обсидиан\Обсидиан`:
   `Обсидиан/Встречи Zoom/ГГГГ/ММ/ГГГГ-ММ-ДД/ЧЧ-ММ — <тема>.md`
   (время — по **первому файлу** сессии; первый компонент обязательно `Обсидиан`).
   Затем одной командой скопируй файл в Obsidian и отметь в БД:
   ```
   python programs\zoom_state.py publish "<путь к локальному конспекту>" --obsidian "Обсидиан/Встречи Zoom/ГГГГ/ММ/ГГГГ-ММ-ДД/ЧЧ-ММ — тема.md"
   ```
   Она сама создаст/перезапишет заметку, проставит `obsidian_path` и статус `done`
   (всем файлам сессии, если конспект покрывает сессию).
5. Перед отчётом пройди «Самопроверку» из регламента: перечитай каждый записанный конспект и убедись,
   что есть `Обзор:` и нужные секции, объём ≤ ~60 строк, хронология ≤ 7 пунктов. Не отчитайся «готово»,
   если конспект не записан или остался в старом стиле.
6. Проверь, что в папке дня в Obsidian **ровно одна** заметка на эту встречу (никаких дублей).
7. Обнови таблицу сделанных конспектов и состояние обработки в `programs\MEMORY.md`.
8. В ответ выведи: сколько конспектов создано, их пути и что осталось в `pending`.

Если `ready_for_konspekt` пуст — ничего не создавай, просто сообщи, что новых
записей для конспекта нет.
