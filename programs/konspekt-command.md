# Промпт-команда автономного конспекта (вызывается `konspekt.ps1`)

Цель обработки — в строке `Target:` сообщения запуска; если её нет — весь проект
`D:\video_cast\zoom`.

Ты выполняешь стандартный регламент конспекта встречи. Сначала прочитай файл
`programs\prompt-konspekt.md` целиком и строго следуй ему.

Действия:
1. Синхронизируй состояние: `python programs\zoom_state.py sync`, затем
   `python programs\zoom_state.py pending --json`.
2. Разбери `pending`: `ready_for_konspekt` — готовые сессии/файлы для конспекта;
   `no_transcript` — пропусти, транскрибацию самостоятельно не запускай.
3. Для каждой готовой сессии — ОДИН компактный конспект по шаблону из регламента
   (frontmatter обязателен; на сессию: начало по первому файлу, длительность суммарная,
   файлы — все файлы сессии).
4. Сохрани конспект рядом с аудио (`<первый файл сессии>_конспект.md`) и в Obsidian
   по пути из регламента, затем отметь в БД: `session done <id>` для сессии или
   `mark "<аудио>" done --konspekt ... --obsidian ...` для одиночного файла.
5. Обнови таблицу сделанных конспектов и состояние обработки в `programs\MEMORY.md`.
6. В ответ выведи: сколько конспектов создано, их пути и что осталось в `pending`.

Если `ready_for_konspekt` пуст — ничего не создавай, просто сообщи, что новых
записей для конспекта нет.
